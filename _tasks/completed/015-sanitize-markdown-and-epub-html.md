# Sanitize Markdown And EPUB HTML

Severity: high

Evidence: Markdown and EPUB builders inject generated/imported text into HTML.

Implementation steps:
- Add an allowlist sanitizer for Markdown HTML.
- Escape Bible, footnote, and glossary text before EPUB markup.
- Keep intentional EPUB links/tags generated by code.

Acceptance criteria:
- Script tags and event attributes are removed or escaped in browser and EPUB output.

Tests:
- Add malicious Markdown, footnote, chapter text, and glossary tests.
